# Cookie and Similar Technologies Policy

**Effective date:** September 14, 2026

## Current position

LDR Companion's native mobile app does not use browser cookies, advertising
identifiers, third-party analytics, tracking pixels, device fingerprinting, or
third-party embeds. It uses device storage only for strictly necessary or
user-requested purposes:

| Storage                              | Purpose                                         | Required?                         |
| ------------------------------------ | ----------------------------------------------- | --------------------------------- |
| SecureStore / authentication storage | Keep the signed-in session secure               | Necessary for a signed-in account |
| Local app cache                      | Restore games and synchronize app state         | Necessary for core functionality  |
| Theme preference                     | Remember the palette selected by the user       | Requested preference              |
| APNs device token                    | Deliver push alerts after permission is granted | Optional                          |

Because the current app does not use non-essential cookies or similar tracking
technologies, it does not display a cookie consent banner. A banner that asks for
consent when nothing optional is being set would be misleading.

## Website and future changes

The project does not currently ship a public marketing web application. Public
legal-policy pages should be hosted without non-essential cookies, analytics, or
embedded media where possible.

Before adding analytics, advertising, social widgets, embedded video, session
replay, pixels, fingerprinting, or other non-essential device storage:

1. update the data inventory and this policy;
2. determine the rules in every launch territory;
3. block the technology from loading until opt-in consent where required;
4. make reject and withdraw as easy as accept;
5. retain a record of the consent choice without collecting excess data; and
6. update App Store privacy disclosures.

## Controls and contact

You can sign out to clear the active app session, delete your account in Settings,
change the theme in Settings, and control notification permission in device
settings. Before release, the operator must add its legal identity and a private,
monitored support email to this policy.
